# Palette Color Cycling System

## How it works

Colors are defined as CSS custom properties in the theme files, with different
values per theme. Hugo templates cycle through them using the loop index mod 7.

### 1. CSS variables (one set per theme)

`themes/typeset/assets/css/dark.css`:
```css
html[data-theme="dark"] {
    --nav-color-0: #e19c8c;   /* terracotta  (blended + brightened) */
    --nav-color-1: #f9b17b;   /* peach-orange */
    --nav-color-2: #e04a7d;   /* magenta */
    --nav-color-3: #d9af73;   /* warm gold */
    --nav-color-4: #92caad;   /* sage */
    --nav-color-5: #e2e265;   /* yellow-green */
    --nav-color-6: #d69c80;   /* warm peach */
}
```

`themes/typeset/assets/css/light.css`:
```css
html[data-theme="light"] {
    --nav-color-0: #672f6d;   /* purple */
    --nav-color-1: #3d366a;   /* deep purple */
    --nav-color-2: #ba3b3c;   /* red */
    --nav-color-3: #903554;   /* magenta */
    --nav-color-4: #4e874e;   /* green */
    --nav-color-5: #27233b;   /* dark purple */
    --nav-color-6: #383735;   /* dark grey */
}
```

The dark palette was generated by blending palette colors pairwise (RGB average),
then boosting lightness +0.20 and saturation +0.25 in HSL space so they read
clearly on dark backgrounds.

### 2. Hugo template usage

In any template that loops over items, add `mod $i 7` on the index:

```html
{{- range $i, $item := .Pages }}
<h2 style="font-weight: normal">
    <a href="{{ $item.RelPermalink }}"
       style="color: var(--nav-color-{{ mod $i 7 }})">
        {{ $item.Title }}
    </a>
</h2>
{{- end }}
```

`font-weight: normal` on the heading removes bold — color replaces weight
as the visual differentiator, avoiding fatigue on long lists.

### 3. Where it is currently applied

| File | Element |
|---|---|
| `layouts/partials/nav.html` | top-level nav links + dropdown children |
| `layouts/blogs/list.html` | blog post titles (`h2`) |
| `layouts/index.html` | featured post title (`h2`, fixed color-0) + stream titles (`h3`) |
| `themes/typeset/layouts/partials/header.html` | site title words (uses `slice` of title colors, not nav-colors) |

### 4. Extending to a new element type

**Case A — Hugo loop (recommended):**
Any `range $i, $x := someList` in a layout file. Add to the title/link:
```
style="color: var(--nav-color-{{ mod $i 7 }})"
```

**Case B — CSS only (no Hugo loop), e.g. icon grids, tag clouds:**
Use `nth-child` in a CSS block:
```css
.my-list li:nth-child(7n+1) a { color: var(--nav-color-0); }
.my-list li:nth-child(7n+2) a { color: var(--nav-color-1); }
.my-list li:nth-child(7n+3) a { color: var(--nav-color-2); }
.my-list li:nth-child(7n+4) a { color: var(--nav-color-3); }
.my-list li:nth-child(7n+5) a { color: var(--nav-color-4); }
.my-list li:nth-child(7n+6) a { color: var(--nav-color-5); }
.my-list li:nth-child(7n+7) a { color: var(--nav-color-6); }
```
Replace `.my-list li` with the actual selector. Works for social icon rows,
tag lists, card grids rendered by the browser — anything without a Hugo index.

**Case C — changing the palette:**
Edit the 7 variables in both `dark.css` and `light.css`. The number 7 is not
magic — if you add or remove colors, change the `mod N` in every template and
the `7n+N` in every nth-child block to match the new count.
